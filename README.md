# Recursive Turtle Tree Generator

This is a Python project that uses the built-in `turtle` and `random` graphics modules to generate a fractal-like tree with randomized branch lengths and leaves.

## Features
- **Fractal Tree Generation:** Built using recursive functions.
- **Randomization:** Uses `random()` to give every generated tree a unique natural look.
- **Custom Visuals:** Dark background, wooden brown branches, and green leaves at the end of each branch.

## Prerequisites
- Python 3.x installed on your system (The `turtle` module comes pre-installed with standard Python distributions).

## How to Run
1. Clone this repository or download the source code.
2. Open a terminal or command prompt in the project directory.
3. Run the Python script:
   ```bash
   python main.py
